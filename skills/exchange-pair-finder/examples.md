# exchange-pair-finder — examples

> Check if a coin exists on Binance/OKX

---

## English

```
/exchange-pair-finder BILL USDT
```

```
/exchange-pair-finder PLAY USDT on Binance and OKX
```

---

## العربية

```
/exchange-pair-finder ابحث عن BILL/USDT في Binance و OKX
```

```
/exchange-pair-finder هل PLAY متوفرة
```
