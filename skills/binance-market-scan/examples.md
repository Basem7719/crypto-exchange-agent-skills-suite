# binance-market-scan — examples

> Public market data from Binance

---

## English

```
/binance-market-scan BTC/USDT
```

```
/binance-market-scan ETH/USDT timeframe=4h
```

---

## العربية

```
/binance-market-scan احضر بيانات BTC/USDT
```

```
/binance-market-scan ETH على فريم 4 ساعات
```
