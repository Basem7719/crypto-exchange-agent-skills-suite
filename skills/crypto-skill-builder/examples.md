# crypto-skill-builder — examples

> Create a new skill in this suite

---

## English

```
/crypto-skill-builder skill_name=binance-margin-analyzer purpose="Analyze Binance margin" category=analysis mode=analysis
```

```
/crypto-skill-builder skill_name=okx-options-snapshot purpose="OKX options chain" category=data
```

---

## العربية

```
/crypto-skill-builder اضف مهارة جديدة لتحليل margin
```

```
/crypto-skill-builder ابني skill لمتابعة unlocks
```

---

## Notes

- All commands above assume the suite is installed under `~/.claude/skills/` (Claude Code) or the equivalent path for OpenClaw / Cursor / Hermes. See [`../../INSTALL.md`](../../INSTALL.md).
- For the full input/output details, see [`SKILL.md`](./SKILL.md).
- For a typical multi-skill flow that uses this skill, see [`../../workflows/`](../../workflows/).
