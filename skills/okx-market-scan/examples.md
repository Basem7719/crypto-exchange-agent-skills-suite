# okx-market-scan — examples

> Public market data from OKX

---

## English

```
/okx-market-scan BTC-USDT
```

```
/okx-market-scan BTC-USDT-SWAP timeframe=1h
```

---

## العربية

```
/okx-market-scan احضر بيانات BTC على OKX
```

```
/okx-market-scan BTC swap على 1h
```
